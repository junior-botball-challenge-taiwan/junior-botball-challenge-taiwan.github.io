## 🤖 賽事核心特色

1. **100% 純自主運行 (Autonomous Control)**  
   不使用任何手動或遙控器操作，考驗選手演算法設計、感測器即時融合與機械運動精準度。
2. **直通三大國際舞台**  
   - 🇺🇸 **美國 GCER (Global Conference on Educational Robotics)**：全球 Botball 最高殿堂。
   - 🇦🇹 **奧地利國際挑戰賽 (ECER)**：歐洲頂尖機器人競技與工程論壇。
   - 🇹🇭 **泰國國際邀請賽 (Thailand Invitational)**：亞洲青少年機器人交流樞紐。
3. **全齡階梯式挑戰**  
   涵蓋國小組（低年級、中高年級）、國中組、高中組，提供循序漸進的程式教育路徑。
